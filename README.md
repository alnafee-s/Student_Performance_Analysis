# Student Performance Analysis Dashboard

A Power BI dashboard analyzing student performance data — looking at how study habits, attendance, and class participation relate to overall scores and grades.

## Dataset

10,000 student records with the following columns:
- `student_id` — unique student identifier
- `weekly_self_study_hours` — hours spent studying per week
- `attendance_percentage` — class attendance percentage
- `class_participation` — participation score
- `total_score` — overall score
- `grade` — final letter grade (A, B, C, D, F)

## Dashboard

The dashboard includes:
- KPI cards: total students, average study hours, participation, attendance, and score
- Average score by grade
- Score trend against weekly study hours
- Student count distribution by grade (pie chart)
- Class participation by grade
- Combined score and student count by grade (stacked bar)

## Files

- `student_performance.csv` — the raw dataset
- `student_analysis_dashboard.pbix` — the Power BI file
- `student_analysis_dashboard.pdf` — a static export of the dashboard
